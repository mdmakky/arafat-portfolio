# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Stack

Astro, plain CSS with custom properties, and small vanilla `<script>`s for interactions, deployed on Vercel. Chosen by the user (Claude recommended it). React islands and the `motion` library are only to be added when an interaction needs them.

## Users

Two audiences with equal priority:
- **Recruiters and engineering hiring managers** who open the link from a CV or LinkedIn. They are deciding in a few minutes whether to interview Arafat for a Junior SWE or backend role.
- **Freelance clients** looking for someone to build an app or website. They want proof that he ships working products.

## Product Purpose

The personal portfolio of Md. Arafatuzzaman ("Arafat", GitHub `mdmakky`). It replaces the old site at portfolio-mdmakkys-projects.vercel.app (repo `mdmakky/Portfolio`), which the user finds generic. Success is when a visitor quickly understands that Arafat builds and ships real products (backend, full-stack, Flutter, AI) and then contacts him or opens his work.

## Positioning

He is a builder who ships products for everyday Bangladeshi life, in Bangla and English:
- **Rivo**: an offline money tracker that handles cash, bank, bKash and Nagad.
- **Meal Bazar**: settlement for a shared mess (meals, bazar, month-end hisab).
- **Tong**: real-time chat.
- **Mentora**: RAG-based study help.

The pitch is backend depth (APIs, real-time, RAG) combined with finished, used apps, rather than tutorial projects.

## Operating Context

- Visitors arrive from a CV, LinkedIn, GitHub or a direct share, on desktop and mobile.
- Recruiters skim the site. Clients look for live links and a way to get in touch.
- Arafat is currently job-hunting for Backend / Junior SWE roles.

## Capabilities and Constraints

- Static site with no backend. GitHub data (contributions, languages) is fetched at build time.
- Must support reduced motion. Animation must not hide content.
- Undecided: a full Bangla version (later phase), a custom domain, and a blog (later phase).
